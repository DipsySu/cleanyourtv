# 动森与塞尔达主题 UI 验收

2026-10-23，在 Xiaomi MiTV-MFTR0（Android 11、1920×1080）上检查遥控器操作、截图和录屏。本轮只调整启动器的呈现，主题资源沿用动森 v1、塞尔达 v2。

## 修正的问题

| 路径 | 原问题 | 最终行为 |
| --- | --- | --- |
| 主页 → 顶栏 | 关闭高级效果时，轻微底色变化不足以定位焦点 | 动森使用深绿底与奶油色文字；塞尔达使用金底与深色文字。边框、徽记、叶脉一起响应焦点 |
| 网络按钮 | 白色网络图标在浅色圆盘上对比不足 | 普通和聚焦状态均使用深色圆盘；保留实际 Wi-Fi / Ethernet 图标，网络刷新不会重复包裹徽记 |
| 主页 → 设置 → 弹窗 | 新主题进入设置后回到通用灰色界面 | 页面、标题、行、缩略图占位、Radio 和正负按钮延续森林绿或石板金配色 |
| 数字选项 | 已选值获得焦点后，与未选值获得焦点的外观相同 | 亮底表示焦点，2dp 主题色边框和轻微底色表示当前值；已选＋聚焦优先匹配，保留 3dp 选中边框。金色焦点使用深边确保可见 |
| 主题 / 壁纸列表 | 固定行高和单行名称会硬截断长标题 | 名称最多两行、末尾省略，行高随内容增长，保留完整可访问名称 |
| 应用标签 | 中英文的字体族、大小和背景上的清晰度不协调 | 两套新主题统一使用系统 medium 字体、15sp、轻微阴影；非焦点透明度提高至 0.88 |

字体族统一不代表所有语言字形具有完全相同的笔画粗细。卡片名称宽度在创建和绑定时跟随实际卡片宽度，不会沿用 XML 的 180dp 初始值。

## 真机检查结果

1. **主页：通过。** 两套主题的输入源、Wi-Fi、设置焦点逐项检查；应用名称无可见字形裁切，角色保留完整轮廓，未增加 app 小徽章。顶栏焦点文字与底色的计算对比度约为动森 9.24:1、塞尔达 8.05:1。
2. **设置与选择器：通过。** 检查已选 6 列时把焦点移到 4 列，再移回；当前主题与其他聚焦主题同时可辨。壁纸选择器取消按钮、高级效果确认弹窗的焦点和返回均正常。
3. **长名称：通过。** 临时导入同 ID、同版本的 60 字中文名称测试包，主题和壁纸列表均正确折行、省略；单选按钮、说明文字和取消按钮保持可见。测试后重新导入原塞尔达 v2，核对三个主题的 ID、版本和名称。
4. **切换与应用返回：通过。** 实际遥控器完成塞尔达 → 动森 → 塞尔达 → 动森；两套主题均成功打开 Emby 并返回桌面。强制停止再启动后，塞尔达 v2 仍为当前主题。
5. **旧主题：通过本轮回归。** 奥德赛主页与设置页保持原配色和布局。

日期装饰和塞尔达全身立绘比例经过复核后保留。宽窄不同来自素材姿态；通过拉伸或裁去头脚统一体积会破坏角色。主页的快捷菜单继续使用已有深色浮层。
