# 主题切换保留布局与塞尔达暖色调整

2026-10-23，Xiaomi MiTV-MFTR0 / Android 11 / 1920×1080。

## 偏好逻辑

之前在设置中选“程序坞下方行数 0”后，切换主题会恢复为主题默认的 1。原因是主题激活会增加 revision，`Config.load()` 发现签名变化后把布局、动画和壁纸选择一起删除。不是数值 0 保存失败。

现在列数、程序坞下方行数、动画和高级效果是全局用户偏好，优先于主题默认值。切换主题、重复激活、更新主题 ZIP、legacy 推送或 `theme.sh --reset` 都保留它们。主动选择设置中的“跟随主题”才清空这些覆盖值。没有手动设置时，仍采用当前主题默认值。

固定壁纸文件名和“无壁纸”仍是主题级选择：换主题或主题签名改变时恢复该主题的壁纸默认值，避免把同名文件误当成上一套壁纸。首次升级及未挂载存储的保护逻辑保留。

## 视觉

- 动森 v2、塞尔达 v3 默认下方 0 行；用户手动行数优先。首页 Dock 下移，向下仍能浏览应用，Home 回到 Dock。0 行表示不预留完整网格行，屏幕最下方仍可能露出下一行的一小部分。
- 塞尔达壁纸改为柔和夕照、暖灰绿山野和淡暖雾气，保留空岛、城堡、神庙和林克的构图。
- 卡片改为暖灰绿渐变和低透明沙金内边，移除硬 L 形角标。渐变在尺寸变化时缓存；完整角色 contain 比例不变，16 张官方图片的字节和 SHA-256 不变。
- 时钟、顶栏与设置页使用更柔和圆角和暖深绿 / 沙金配色。焦点仍为明确的沙金实底与深绿文字；选中状态和焦点分开显示。动森、奥德赛及其它卡片回退样式沿用原行为。
